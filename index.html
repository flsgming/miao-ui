Mở hóa đơn chi tiết trên GitHub

Bước 1: Tạo 1 repo Public riêng (vd: miao-ui), tải file này lên và đổi tên thành index.html (file không chứa token nên công khai vẫn an toàn tuyệt đối).

Bước 2: Vào Settings → Pages → Branch: main → Save. Mở link GitHub Pages trên Safari iPhone → Chia sẻ → Thêm vào Màn hình chính.

Bước 3: Ngay trên tab Hồ sơ này, bấm Tạo Classic Token toàn quyền → dán Token → chọn repo build Private → sang tab Sync bấm Đẩy build.yml lên Repo là xong 100%.
